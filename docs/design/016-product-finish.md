# Goal016: 操作と情報の整理

確認日: 2026-10-14 JST。Goal013の作品中心の構成を維持し、入口、動き、比較、印刷の情報順を整えた。幾何・検査・保存形式・モデル接続・受付台帳・監視は変更していない。

## 変更と理由

| 場所 | 変更 | 確認する体験 |
| --- | --- | --- |
| ホーム | 自分の絵とサンプルを主導線にし、再開は作品一覧へ移動。短文で紙工作と型紙が成果であることを示す | 初回開始、既存作品の名前と再開、読込失敗 |
| 動き | 方向と距離をまとめ、守る条件、希望一欄、寸法支援とAIの順にする。原寸表示では不要なパン・全体ボタンを隠す | 倍率と工作寸法の独立、原本保持、外部送信の明示 |
| 比較 | 現在・希望・候補、変更量、絵と紙の維持条件を先に示す。検査は詳細へ | 採用前に原本を変えない、代案の違い、採否後のフォーカス復帰 |
| 印刷 | 選択したPDFのページ数と内容を一か所に表示する。取得済みガイドの版と編集中の版を区別 | 全部・型紙・説明の実PDFと一致、過去版ガイドの保持 |
| 組立 | 工程の下にも次・前の操作を置き、移動先の見出しへフォーカスを戻す | 閲覧位置の保存、キーボード操作、閲覧と実物完成を混同しない |
| 保存 | 通常のヘッダー表示を短くし、詳細は支援技術・ツールチップと保存画面へ。失敗時の復旧操作を維持 | 自動保存、容量超過、2タブ競合、旧ファイル、下書き保持 |

狭幅では作品と設定を縦に続ける。希望欄は16px以上、主要操作は44px以上を維持する。実機ソフトキーボードの検証と、Chromium/WebKitの画面幅による検証は区別する。

## 参照した整理原則

[Goal013の参照記録](013-oss-reference.md)を土台にした。今回追加で読んだ一次資料は次のとおり。いずれも公式説明の参照であり、ログインした製品の操作検証や画面の複製ではない。

- [Notionのサイドバー](https://www.notion.com/help/navigate-with-the-sidebar): 必要な領域を表示・折り畳む整理。今回は候補が出たときに入力を畳み、比較と採否を同じ場所に置く。
- [Linearの環境設定](https://linear.app/docs/account-preferences): 起点や表示・通知を選べる整理。今回は通常状態を静かにし、作業に必要な状態と復旧操作を残す。
- [GitHub Projectsのボード表示](https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/customizing-the-board-layout): 表示する情報を作業単位で選ぶ整理。今回はPDFの選択に対応する内容だけを表示する。

コード、CSS、アイコン、ロゴ、画面画像は取り込んでいない。新しいUI基盤や依存も追加していない。

## 証拠の区別

変更前後の画面・検証ログは `artifacts/goal016/before/` と `after/`、公開確認は `public-check/` に記録する。ローカルの手動候補・テスト専用応答を、公開実AIの証拠にしない。提出用の画像と動画は、新しい公開版で取得した別の実AI記録だけから制作する。実物の印刷精度・摩擦・強度・工作動作は未検証のままとする。
