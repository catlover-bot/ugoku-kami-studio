## 2. 見せる体験と説明

同封原稿を土台に、次の流れを一つの制作体験として紹介します。

絵を選ぶ → 動かす部分・方向・距離を決める → 希望と守りたい条件を入力する → AIの案を比べる → 作者が採用する → 原寸型紙・組立ガイドを受け取る → 保存して続きから再開する。

説明は「操作 → 結果 → 利点」を基本にしてください。

例：
- 「AIで案をつくる」を押す → 20mmと25mmを比較 → 絵の大きさと紙枚数を保った変更を選べる。
- PDFの内容を選ぶ → 型紙1枚と説明4ページを取得 → 必要な資料をまとめて印刷できる。
- ガイドを開く → 使う部品と接着箇所が分かる → 工程ごとに作業を進められる。
- 作品を保存する → 開いていたガイドも再開 → 自分のペースで制作を続けられる。

現在の実依頼文は「右へ25mm動かしたい。絵の大きさと紙の枚数は変えない」です。20→25mm・同じ第2版の実録と取得PDFをそのまま使います。「あと5mm」は変化の要約に使えても、送信した文章を書き換えて表示することはしません。

## 3. 編集方針

旧UIや旧モデル実録へ戻さず、Goal016の現行UIの原録画・採用正本・実PDFを使用します。実AIの入力、候補、採用の映像は現存する実録を使い、モデル再実行はしません。

同じ採用作品を別の場所で開いた場面は「採用した作品を開く」「続きから再開」と説明できます。環境の地名や収録場所を表示する必要はありません。一方、「ノーカット」「一回の連続収録」「すべて3.667秒で完成」とは説明しません。速度変更や理解に影響する静止表示には、必要な場面だけ短く「倍速」「拡大」等を示し、処理待ち時間を偽りません。

既存の字幕が映像に焼き込まれていれば、差し替え字幕だけでなく映像も安全な原素材から再出力します。色付きの大きな帯を被せたり、生成画像で画面を作り替えたりしません。数値、検査結果、候補、エラー表示など、実UIの内容は変更しません。

アプリやPDFそのものにある必要な工作上の注意・利用条件を削除する指示ではありません。それらを紹介ナレーションで繰り返す必要がない、という編集上の変更です。説明対象だけに寄る自然なトリミングは可能ですが、安全警告や検査結果を消して偽の成功画面を作りません。

構成図は採用済みの整理版を維持します。料金・台帳・運用の説明を新しく動画へ増やしません。生成した実物写真、試していない組立成功、今回起きていない多段のAI再調整は追加しません。紹介は実画面での操作と、実際に取得できる型紙・ガイドに集中します。

終盤の50mm校正線は、PDF説明の一部へ移して必要なら「100%で印刷すると、原寸の型紙として使えます」と短く説明します。最後は既存の採用作品プレビューまたはキット全体を見せ、次の言葉で締めてください。
