# Goal009 — 接続先を分けた提出準備と待ち時間の改善

開始版は `5ae518e672c1164633df2b602ab806ec3053db7b`。2026-10-05の追加指示を根拠に、既存Gemma/Ollamaを維持し、提出候補としてCloud Run Web/API＋Vertex AI経由のGeminiを準備する。前回の非公開試験は終了しており、その実行許可を流用しない。

## 今回の範囲

- 大会参加特典の300ドルクーポンは、初回無料トライアルのクレジットと分ける。指定済みproject・請求先を維持し、適用先・残額・終了日・対象範囲・現在の請求先種別だけを再確認する。過去に確認済みのログイン一致・project用途は繰り返し質問しない。個人識別子と明細はGit対象外の資料へ保管する。
- Developer APIとは別のVertex接続を実装し、Google CloudのADCと実行SAを使う。APIキーの差替え、長期秘密鍵の新規発行、失敗時の自動接続切替は行わない。
- Flash系は一モデルに固定して、APIロケーション、ツール呼出し、料金を公式資料で確認する。Cloud Run東京配置とモデルAPIの処理場所を区別する。
- 共通の設計コア・固定条件・検査・採用・保存・PDFを再利用し、モデル向け入力の重複と不要な再推論を減らす。中断修正を維持する。CPU版Gemmaの高速化だけを目的に全体を作り替えない。
- 作品を中央に置き、希望入力は一か所、比較は同じ操作領域を維持する。接続先変更の設定項目を通常の制作画面へ増やさない。
- 一モデル・最大4件を基本とする次の限定試験を、クレジット控除前の標準料金換算5ドル以内を管理目安に計画する。初回・別依頼・不成立・中断後復帰、同版PDF、待ち時間・正確さ・使用量を確認する。1件と全試験の呼出し・入力・出力・時間上限を明記する。
- クーポン適用範囲と費用を示した後、必要なAPI・IAM・推論・デプロイ・片付けの実行範囲をまとめて確認する。5ドルを厳密な課金遮断と説明しない。

ローカル実装・模擬検証・提出素材案の更新・検証済み変更のmain通常統合とpushは許可されている。有料移行、外部API実推論、クラウド書込み、一般公開、300ドル全額消費、YouTube公開・Zenn最終提出は今回許可されていない。
